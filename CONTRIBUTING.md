# Contributing to Maestro

Thanks for your interest in contributing!

## Setup

```bash
npm install
cd webview-ui && npm install && cd ..
npm run build
```

Press `F5` in VS Code to launch the extension in a new Extension Development Host window for manual testing.

## Making changes

1. Fork the repo and create a branch off `main`.
2. Make your changes, keeping them focused and scoped to one concern.
3. Run `npm run build` to confirm the extension and webview both build cleanly.
4. Open a pull request describing what changed and why.

## Reporting issues

Please open a GitHub issue with steps to reproduce, expected behavior, and
actual behavior. Include your VS Code version and OS.
